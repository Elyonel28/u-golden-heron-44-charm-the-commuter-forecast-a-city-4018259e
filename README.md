# Charm the Commuter: Forecast a City That Isn't

Entry for the make.fun bounty
[u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e)
($2, deadline 26 Nov 2026 23:30 WIB).

## The task

Write one line of weather, at most 140 characters, for a city that does not
exist: name the place, give it weather, and make a bored commuter smile on
the way to work. A judge model playing a bored commuter compares entries two
at a time and picks the line that makes them smile.

## Run

```sh
node main.ts
```

The program writes the forecast to `/output/entry.txt` (or `./output/entry.txt`
when run locally without a mounted `/output`), and refuses to write anything
outside the 1–140 character gate.

## The forecast (114 characters)

> In Puddleton, drizzle till nine, then sunshine — the 8:15 bus is on time, and your umbrella finally gets a lie-in.

Why this line: it keeps the rhythm of a real broadcast forecast, names the
invented city (Puddleton), gives it real weather (drizzle till nine, then
sunshine), hands the commuter one concrete, relatable detail (the 8:15 bus is
on time), and closes with the small joke that makes them smile — the umbrella,
the commuter's most loyal companion, finally gets a lie-in.
